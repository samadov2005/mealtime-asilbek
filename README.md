# MealTime

MealTime - talaba va ofis foydalanuvchilari uchun sog'lom tushlik buyurtma demo interfeysi.

## Tuzilishi

- `index.html` - sahifalar markup'i
- `css/styles.css` - asosiy dizayn, ranglar va responsive qoidalar
- `js/app.js` - ekranlar, tanlash, modal va summa logikasi
- `assets/images/` - hero va taom rasmlari
- `mealtime-2.html` - eski bitta faylli original versiya

## Rang yondashuvi

Yashil ranglar sog'liq, ishonch va tabiiylik hissini beradi. Cream fon interfeysni yumshatadi, amber focus holatlari esa harakatga undovchi iliq urg'u bo'lib ishlaydi.
